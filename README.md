# ICU Patient Monitoring Dashboard

A simple HTML/CSS/JavaScript project demonstrating a basic ICU patient-vital monitoring dashboard.

## Features
- Heart rate display
- SpO₂ display
- Temperature display
- Respiratory rate display
- Simulated vital-sign updates

## How to run
Open `index.html` in any web browser.

## Note
This is an educational/demo project and is not intended for real clinical decision-making.
